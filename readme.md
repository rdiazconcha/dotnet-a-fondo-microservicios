# .NET a fondo: Microservicios

## Curso de LinkedIn Learning

Aprende a diseñar e implementar arquitecturas de microservicios con .NET y ASP.NET Core. En este curso descubrirás los principios fundamentales de este enfoque arquitectónico, sus principales características y las ventajas y desafíos que plantea frente a otras alternativas. A través de un proyecto práctico, conocerás cómo desarrollar servicios independientes, utilizar contenedores para facilitar su despliegue e incorporar posteriormente prácticas de DevOps.  Una formación para construir soluciones distribuidas y tomar decisiones arquitectónicas con mayor criterio.
